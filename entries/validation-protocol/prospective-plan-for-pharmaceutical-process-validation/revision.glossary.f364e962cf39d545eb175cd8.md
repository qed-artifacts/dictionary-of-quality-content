# Validation protocol

*Scope: prospective plan for pharmaceutical process validation*

A validation protocol is a prospective document that states how a specified validation study will be conducted and judged.

For a pharmaceutical process, it identifies the scope, important parameters, tests and sampling, data to record, and acceptance criteria. Responsibilities and the basis for those criteria should be clear.

Completing and evaluating the study provides validation evidence; approving the protocol alone does not establish that the process performs reliably.

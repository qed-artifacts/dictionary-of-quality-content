# Failure mode

*Scope: specified way an item or process fails*

A failure mode is a specified way in which an item, process, or system fails to perform an intended function.

Depending on the analysis, it may describe a visible symptom, a functional failure, or a physical mechanism. State the intended level: what one analysis calls a mode may be treated as a cause or effect in another.

The same item can have several failure modes, so a useful description identifies the affected function and the particular manner of failure.

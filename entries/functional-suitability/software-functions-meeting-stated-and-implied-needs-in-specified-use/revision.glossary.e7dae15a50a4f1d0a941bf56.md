# Functional suitability

*Scope: software functions meeting stated and implied needs in specified use*

In software quality, functional suitability is how well a product's functions serve stated and reasonably implied user needs under specified conditions.

It includes whether needed tasks are covered, results are correct, and the functions help users complete those tasks.

A feature-rich product can still be unsuitable if it omits an essential task or gives the wrong result.

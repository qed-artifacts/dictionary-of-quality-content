# Data drift

*Scope: input-feature distribution change in machine-learning monitoring*

In machine-learning monitoring, data drift is a change in the statistical distribution of input features relative to a stated training or monitoring baseline.

A shift in a feature's frequency, mean, spread, or other properties can challenge assumptions under which a model was trained.

Detecting drift calls for investigation; it does not by itself prove that predictions have worsened or that retraining is needed.

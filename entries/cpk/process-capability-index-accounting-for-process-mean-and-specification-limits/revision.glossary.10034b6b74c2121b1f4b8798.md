# Cpk

*Scope: process capability index accounting for process mean and specification limits*

Cpk is a process capability index that compares within-process spread with the nearer specification limit, taking the process mean into account.

It reflects both variation and how the process is positioned between the limits; when a two-sided process is centered, Cpk equals Cp.

A stable process and suitable distributional model are needed before using it to predict future conformance.

# Data lineage

*Scope: metadata tracing data movement and transformation*

Data lineage is metadata showing where data came from and how it moved and changed through systems or processes.

It may describe the path at a broad system level or in detail down to particular fields and transformation rules.

Lineage helps investigate surprising results and data-quality problems, but a known path does not by itself prove that the original data were correct.

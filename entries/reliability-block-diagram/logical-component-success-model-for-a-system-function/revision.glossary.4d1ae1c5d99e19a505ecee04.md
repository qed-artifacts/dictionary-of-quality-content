# Reliability block diagram

*Scope: logical component-success model for a system function*

A reliability block diagram is a model showing which components must function, alone or in alternative paths, for a specified system function to succeed.

Each block represents a needed function or component state; a complete path of functioning blocks represents system success.

The diagram expresses functional dependence, not necessarily physical wiring, and reliability calculations require stated assumptions about component behavior.

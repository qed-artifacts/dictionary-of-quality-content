# Fault

*Scope: nonfunctional item state in fault-tree reliability analysis*

In fault-tree reliability analysis, a fault is a state in which an item cannot perform a specified function.

A fault may result from a failure event or from a systematic problem introduced in design, production, or operation.

The term identifies the nonfunctional state; a failure event describes the transition into that state.

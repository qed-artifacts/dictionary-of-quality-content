# Cost-utility analysis

*Scope: health economic comparison using preference-weighted outcomes*

In health economics, cost-utility analysis compares alternatives' costs with health outcomes expressed in preference-weighted units, commonly quality-adjusted life-years.

It can express the added cost of an option in relation to the added quality-adjusted life-years it is expected to produce.

The result depends partly on how health-state utility is measured, so the outcome unit and comparison must be stated.

# Data integrity

*Scope: valid links among related records in relational data*

In relational data, data integrity is the extent to which required links among records are present and valid.

For example, an order linked to a customer ID that has no corresponding customer record fails this check.

This sense concerns relationships among data; it does not by itself cover every aspect of accuracy, security, or protection from alteration.

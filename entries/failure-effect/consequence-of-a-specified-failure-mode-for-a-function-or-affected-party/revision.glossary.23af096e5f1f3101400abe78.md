# Failure effect

*Scope: consequence of a specified failure mode for a function or affected party*

A failure effect is a consequence that may result when a specified failure mode occurs.

Describe the effect at a stated level, such as the affected component, system, service, or user. One failure mode may have several effects at different levels.

The effect answers what happens because of the failure; the failure mode describes how function is lost, and a cause explains why that mode arose.

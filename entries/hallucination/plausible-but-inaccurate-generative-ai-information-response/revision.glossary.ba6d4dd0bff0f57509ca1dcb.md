# Hallucination

*Scope: plausible but inaccurate generative-AI information response*

In a generative-AI information response, a hallucination is plausible-sounding content that conflicts with the best available evidence.

Fluent wording can make the error seem credible, so important factual claims need checking against evidence outside the generated answer.

In this sense, it is an unintentional output error, not deliberately generated disinformation.

# Loss

*Scope: loss counted in cost-benefit appraisal*

In cost-benefit appraisal, a loss is a reduction in a valued resource or condition attributable to a proposed project.

A loss can count as a social cost even when it has no market price, as when a project removes a valued natural amenity.

Estimating its monetary value can be difficult; the stated appraisal should make that uncertainty visible.

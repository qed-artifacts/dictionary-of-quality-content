# Lean

*Scope: organizational approach to value, flow and improvement*

Lean is an approach to organizing and improving work so that it delivers value with less waste and more reliable flow.

Practices may include clarifying value for the user, mapping the work, reducing unnecessary steps, using pull where appropriate, and learning from problems. The practices must fit the setting.

A single tool or cost-cutting exercise does not, by itself, establish a lean system. Look for how the work, people, and continuing improvement fit together.

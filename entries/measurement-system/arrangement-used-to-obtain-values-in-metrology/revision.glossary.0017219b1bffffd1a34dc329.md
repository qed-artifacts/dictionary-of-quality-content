# Measurement system

*Scope: arrangement used to obtain values in metrology*

In metrology, a measurement system is the instruments, procedures, people, and operating conditions used together to obtain values for a specified quantity.

Its configuration includes the reference, test item, method, and environment where these affect the result.

Variation from the measuring arrangement can be mistaken for variation in the subject being measured.

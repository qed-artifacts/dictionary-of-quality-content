# Defect density

*Scope: identified software defects per specified software-size unit*

In software engineering, defect density is the number of identified defects relative to a specified measure of software size.

The denominator may be code size or functional size; a result must name its size unit and which defects were counted.

Size adjustment can aid comparison, but differences in detection effort or defect definitions can still make two values misleading to compare.

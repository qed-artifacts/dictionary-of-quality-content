# Observability

*Scope: software-service operations*

For a software service, observability is how well its internal state and behavior can be inferred from information it emits while running.

Related metrics, logs, and traces can help locate causes across components rather than merely flag a symptom.

More telemetry alone does not ensure observability; it must answer the questions that matter for that service.

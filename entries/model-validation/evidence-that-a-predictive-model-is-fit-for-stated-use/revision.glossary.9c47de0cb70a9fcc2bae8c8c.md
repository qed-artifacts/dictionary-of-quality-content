# Model validation

*Scope: evidence that a predictive model is fit for stated use*

In predictive machine learning, model validation is the evaluation of whether a trained model is sufficiently fit for a specified task and use.

Methods can include held-out testing or cross-validation to examine performance beyond the data used to fit model parameters.

A favorable score supports a claim only for the population and conditions the validation design can represent; it does not guarantee future performance.

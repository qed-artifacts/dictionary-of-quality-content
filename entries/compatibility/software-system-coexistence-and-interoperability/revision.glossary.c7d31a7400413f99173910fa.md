# Compatibility

*Scope: software-system coexistence and interoperability*

In software quality, compatibility concerns how well a product or system works with others by sharing an environment or exchanging usable information.

Coexistence concerns shared resources without harmful interference; interoperability concerns exchanging information that can be used.

Name the other systems and operating conditions, because compatibility is a relation between them, not an isolated property.

# Continuous improvement

*Scope: recurring evidence-guided improvement work*

Continuous improvement is recurring, organized work to improve how a process or system meets its aims.

It starts with a stated need and a proposed change, then checks what actually happened. An unsuccessful test can still produce useful learning.

Effective changes should become part of routine practice and remain open to later review. Continuous does not mean that performance rises without interruption or that every change is beneficial.

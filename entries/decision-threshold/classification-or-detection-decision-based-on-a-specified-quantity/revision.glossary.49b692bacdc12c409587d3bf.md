# Decision threshold

*Scope: classification or detection decision based on a specified quantity*

A decision threshold is a specified value or boundary at which a decision rule changes its classification or prescribed action.

A complete threshold states the quantity, comparison direction, boundary value, and resulting decision.

Moving the boundary can change the balance between missed cases and false alarms; the threshold is a choice, not a measurement result.

# Top event

*Scope: specified unwanted outcome in fault tree analysis*

In fault tree analysis, a top event is the specified unwanted system state or event that the analysis seeks to explain.

It heads the tree; lower events and logic gates show combinations that could bring it about.

Choosing it sets the question and boundary for the analysis. A top event is the outcome under study, not itself an identified root cause.

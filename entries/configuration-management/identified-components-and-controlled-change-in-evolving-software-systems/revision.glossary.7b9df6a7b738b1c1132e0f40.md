# Configuration management

*Scope: identified components and controlled change in evolving software systems*

In software engineering, configuration management identifies a system's components and controls changes to them so its versions and current state remain traceable.

It uses identified items, baselines, version records, and change decisions to show what belongs in a particular configuration.

Version control is one part of the work; it does not alone establish which combination was approved, built, or released.

# Use value

*Scope: direct use or experience in benefit-cost analysis*

In benefit-cost analysis, use value is the value a person derives from directly using or experiencing a good, service, or resource.

It concerns the user's own benefit from that experience, which may be expressed through willingness to pay.

It is not identical to a market price, which need not capture the full value of a use.

# Measurement error

*Scope: metrological difference between result and reference value*

In metrology, measurement error is a measured quantity value minus a reference quantity value.

Its sign and size depend on the chosen reference and the measurement conditions. The exact error usually cannot be known, because the reference itself may be uncertain.

Systematic and random contributions call for different treatment. Measurement error is a difference, whereas measurement uncertainty expresses the spread of values that can reasonably be attributed to what was measured.

# Multi-criteria decision analysis (MCDA)

*Scope: structured comparison using multiple relevant criteria*

Multi-criteria decision analysis (MCDA) is a family of methods for comparing options against several relevant criteria when no single measure settles the choice.

An analysis states the options, criteria, evidence about each option, and how tradeoffs are handled. Some methods use weights and an aggregate score; others compare options without reducing them to one number.

The result depends on these modeling choices. Checking how the recommendation changes under plausible assumptions helps show how robust it is.

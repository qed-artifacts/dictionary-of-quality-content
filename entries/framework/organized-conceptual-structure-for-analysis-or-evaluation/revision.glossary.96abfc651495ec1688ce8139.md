# Framework

*Scope: organized conceptual structure for analysis or evaluation*

A framework is an organized set of concepts, components, or relations used to guide analysis, design, or evaluation.

For example, an educational-quality framework can group teaching components with indicators used to examine them.

A framework makes its chosen structure explicit; its usefulness still depends on how well that structure fits the case and evidence.

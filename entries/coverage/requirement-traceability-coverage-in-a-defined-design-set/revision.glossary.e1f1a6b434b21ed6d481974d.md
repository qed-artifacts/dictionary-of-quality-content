# Coverage

*Scope: requirement traceability coverage in a defined design set*

In a traceability matrix, coverage is the extent to which the requirements in a defined set have the intended links to design outputs and checks.

A coverage claim must name the requirements counted, the kind of link required, and any exclusions; it may be stated as a count or proportion.

A filled link shows a documented connection, not by itself that the design or verification is adequate.

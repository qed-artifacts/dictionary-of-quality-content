# Fault tolerance

*Scope: continued required function despite specified component faults*

Fault tolerance is a system's ability to keep providing a required function when a specified component fault occurs.

Redundant parts or alternate operating modes can help the system continue working after one part fails.

A fault-tolerance claim must name the faults and minimum performance it covers; it does not promise operation under every possible failure.

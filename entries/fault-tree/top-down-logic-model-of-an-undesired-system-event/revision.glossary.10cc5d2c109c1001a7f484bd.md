# Fault tree

*Scope: top-down logic model of an undesired system event*

A fault tree is a diagram that starts with a specified undesired system event and traces combinations of lower-level events that could produce it.

Logical gates show how component faults, human actions, and other conditions combine to reach the top event.

The tree can support qualitative analysis of possible pathways and, with justified input probabilities, quantitative estimates of the top event.

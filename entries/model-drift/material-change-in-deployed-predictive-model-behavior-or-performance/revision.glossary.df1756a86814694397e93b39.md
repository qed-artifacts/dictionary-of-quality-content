# Model drift

*Scope: material change in deployed predictive-model behavior or performance*

In deployed machine learning, model drift is a material change over time in a model's output behavior or predictive performance relative to a stated baseline.

A shift in input data may contribute to drift, but a changed input distribution alone is data drift and does not prove that the model's behavior has changed.

Monitor outputs and outcome-based measures when available, then investigate a detected change before deciding what response is needed.

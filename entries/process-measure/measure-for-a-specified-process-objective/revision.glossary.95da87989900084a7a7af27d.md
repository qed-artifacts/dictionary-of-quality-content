# Process measure

*Scope: measure for a specified process objective*

A process measure is a specified way to assess whether a process is operating or producing results in line with its objective.

It can track an activity, an operating condition, or an output for which the process is responsible.

Its interpretation requires a defined process, objective, and criterion; a desirable organization-wide result may be too remote to guide that process.

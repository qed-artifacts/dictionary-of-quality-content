# Hypothesis test

*Scope: statistical test of a specified null claim*

A statistical hypothesis test uses sample data and a stated model to evaluate a null hypothesis against an alternative hypothesis.

A test statistic and decision rule indicate whether the observed data warrant rejecting the null hypothesis at a chosen significance level.

Failing to reject the null hypothesis does not prove that it is true; the test's assumptions and possible decision errors matter.

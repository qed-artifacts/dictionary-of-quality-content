# Quality loss function

*Scope: modeled loss associated with a quality characteristic departing from a target*

A quality loss function relates the value of a quality characteristic to the loss associated with its departure from a stated target.

It makes the target and the assumed consequence of deviation explicit. Under a continuous loss model, a result can impose some loss even while it remains inside specification limits.

The shape and scale of the function are assumptions to justify for the particular use; a familiar quadratic model is one possible choice, not a universal law of quality.

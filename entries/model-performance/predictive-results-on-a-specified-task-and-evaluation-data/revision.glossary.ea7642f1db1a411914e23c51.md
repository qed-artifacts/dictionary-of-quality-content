# Model performance

*Scope: predictive results on a specified task and evaluation data*

In predictive machine learning, model performance is how well a model carries out a specified prediction task under stated data and evaluation conditions.

It is assessed with measures suited to the task, such as classification or prediction-error measures, on data reserved for evaluation.

A performance claim must name the task, measure, and testing conditions; runtime speed is a different possible sense of model performance.

# Public value

*Scope: value of public action for a political community*

In public governance, public value is the worth of public action in advancing interests and outcomes that a community has reason to regard as important.

Judging it calls for attention to whose interests count and how competing concerns such as effectiveness, fairness, rights, and accountability are weighed.

It cannot be read from a service's financial return or a simple sum of individual preferences alone.

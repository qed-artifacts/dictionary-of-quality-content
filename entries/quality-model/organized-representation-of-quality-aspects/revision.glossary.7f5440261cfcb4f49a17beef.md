# Quality model

*Scope: organized representation of quality aspects*

A quality model is an explicit scheme for organizing the aspects of quality considered for a class of objects.

It may define characteristics, narrower subcharacteristics, and their relationships to measures. Its categories and boundaries depend on the objects and use for which it was made.

A model helps select what to examine; it does not itself set a requirement or establish that a particular object is good. Software and systems quality models are one domain example.

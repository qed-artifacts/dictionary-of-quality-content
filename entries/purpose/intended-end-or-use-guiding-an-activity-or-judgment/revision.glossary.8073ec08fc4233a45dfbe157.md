# Purpose

*Scope: intended end or use guiding an activity or judgment*

A purpose is the end or use an action, object, or inquiry is intended to serve.

A clear purpose names what someone is trying to achieve and for whom. It helps determine which alternatives, requirements, and evidence are relevant.

Purpose is an intention, not proof of success. An activity can have a clear purpose and still fail to achieve it.

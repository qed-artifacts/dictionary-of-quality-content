# Validity argument

*Scope: justification for a specified test-score interpretation and use*

A validity argument is a reasoned case that evidence and assumptions support a specified interpretation or use of test results for a stated population and purpose.

It connects each important inference to relevant evidence and explains why the proposed action follows. Possible counterevidence and limits matter because the same scores can be used for different purposes.

A folder of studies is not a validity argument unless the studies bear on the claims being made. New uses or populations can require a revised argument.

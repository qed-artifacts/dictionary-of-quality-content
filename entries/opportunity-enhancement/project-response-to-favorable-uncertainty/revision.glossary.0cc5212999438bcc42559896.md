# Opportunity enhancement

*Scope: project response to favorable uncertainty*

In project risk management, opportunity enhancement is a planned response that seeks to improve the potential upside of an uncertain favorable event.

The action makes an opportunity more attractive, but the benefit remains uncertain. Exploitation is a stronger response aimed at securing it.

A team should monitor whether the response produced the intended improvement and whether it created new risks.

# Factor

*Scope: input or condition studied in a designed experiment*

In a designed experiment, a factor is an input or condition studied for its effect on a specified response.

The experiment uses particular values, called levels, of the factor and records the response at those levels. The design should say which levels are studied.

A factor is distinct from the response being measured. Calling a variable a factor does not by itself establish that it causes a change.

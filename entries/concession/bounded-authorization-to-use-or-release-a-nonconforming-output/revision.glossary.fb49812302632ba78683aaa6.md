# Concession

*Scope: bounded authorization to use or release a nonconforming output*

In quality management, a concession is a specific authorization to use or release an output that does not meet a stated requirement.

The authorization should identify the departure and any limits, such as quantity, duration, or conditions of use.

It permits the specified exception; it does not erase the nonconformity or establish that every other requirement was met.

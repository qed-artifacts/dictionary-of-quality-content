# Completeness

*Scope: presence of required data for a specified use*

For data, completeness is the extent to which the values that should be present for a specified use are present.

A field may be required for some records and inapplicable to others, so missing values must be judged against the relevant rules and population.

Completeness does not establish accuracy: a filled field can still contain a wrong value.

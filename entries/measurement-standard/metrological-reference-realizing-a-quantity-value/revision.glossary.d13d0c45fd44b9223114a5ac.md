# Measurement standard

*Scope: metrological reference realizing a quantity value*

In metrology, a measurement standard is a reference that realizes a specified quantity value with stated uncertainty for use in other measurements.

It may take the form of an instrument, material, or artifact used to calibrate or compare measuring equipment.

Here, standard means a measurement reference, not a written rule for how to measure.

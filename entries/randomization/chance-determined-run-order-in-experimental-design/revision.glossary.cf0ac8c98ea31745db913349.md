# Randomization

*Scope: chance-determined run order in experimental design*

In experimental design, randomization uses a chance procedure to determine the order of experimental runs.

It helps prevent unmeasured influences that change over time from consistently favoring one factor setting or treatment. The procedure and any restrictions on it should be recorded.

Random order does not fix an unsuitable sample, missing controls, or every source of bias. Random assignment of treatments to units is a related use of the word and should be specified separately when intended.

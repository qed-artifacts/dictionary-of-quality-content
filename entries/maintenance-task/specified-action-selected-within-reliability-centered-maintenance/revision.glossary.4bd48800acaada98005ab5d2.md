# Maintenance task

*Scope: specified action selected within reliability-centered maintenance*

In reliability-centered maintenance, a maintenance task is a specified action, with a basis for when to perform it, intended to preserve or restore an asset’s required function.

A condition-based task responds to an observed indicator; a time-directed task is scheduled by elapsed time or use.

A task is chosen in light of the failure mode, its consequences, and whether the action is feasible and worthwhile. Some failures instead call for redesign or an explicit decision to let the part run until failure.

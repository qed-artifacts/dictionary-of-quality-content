# Time-to-failure

*Scope: elapsed operating or exposure time until an item's specified failure*

Time-to-failure is the elapsed time from a specified starting point until an item first meets a defined failure condition.

The clock and failure rule must be stated: calendar time, operating hours, and cycles can answer different questions.

If the observation ends while the item still works, its exact failure time is unknown rather than zero; the record is censored.

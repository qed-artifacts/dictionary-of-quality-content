# Data accessibility

*Scope: discoverability and usable retrieval of data for an intended user*

Data accessibility is how readily an intended user can find and retrieve needed data in a usable form.

It concerns the path to the data, including whether access is available and the format suits the task, rather than whether the data values are correct.

An authorized user's access needs must be balanced with protection against unauthorized access.

# Fitness for use

*Scope: suitability in a user’s context*

Fitness for use is how suitable an object is for a user’s intended activity under the conditions in which it will be used.

The judgment depends on the user, task, setting, and consequences of failure. An object can meet its written specification yet be unsuitable for the intended use if the specification missed a relevant need.

Fitness for use and fitness for purpose overlap. This wording emphasizes the conditions of actual or intended use, without assigning the phrases mutually exclusive meanings.

# Expected value

*Scope: probability-weighted average of numerical outcomes*

Expected value is the probability-weighted average of the numerical values assigned to possible outcomes.

For discrete outcomes, multiply each outcome's value by its probability and add the products.

It is a model-based average, not a prediction that any one outcome will equal that number; expected utility uses a utility scale rather than necessarily monetary values.

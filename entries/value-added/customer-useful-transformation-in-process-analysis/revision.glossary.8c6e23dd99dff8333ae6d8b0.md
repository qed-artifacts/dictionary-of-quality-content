# Value-added

*Scope: customer-useful transformation in process analysis*

In process analysis, a value-added activity transforms an input into an output that an internal or external customer can use.

The question is whether the step contributes to the output the customer needs, not merely whether it consumes labor or raises cost.

A necessary supporting step may still be classified separately from direct value-adding transformation in a particular process model.

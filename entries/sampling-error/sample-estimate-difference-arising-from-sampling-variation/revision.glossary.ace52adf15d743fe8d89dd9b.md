# Sampling error

*Scope: sample-estimate difference arising from sampling variation*

In estimation, sampling error is the difference between a value calculated from a sample and the corresponding value for the full population that arises because only part of the population was observed.

Different well-drawn samples can produce different estimates even when measurements and calculations are correct.

This is sampling variation, not a mistake in collecting or entering the data; a standard error describes how an estimator varies across samples.

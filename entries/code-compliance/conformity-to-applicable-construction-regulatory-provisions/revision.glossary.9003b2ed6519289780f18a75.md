# Code compliance

*Scope: conformity to applicable construction regulatory provisions*

In construction, code compliance is the extent to which a design or completed work meets the regulatory provisions that apply to it.

A defensible check identifies the governing code, the relevant provisions, the project conditions, and the evidence used to assess them.

Meeting a code is a minimum regulatory judgment; it does not by itself show that every project goal or user need has been met.

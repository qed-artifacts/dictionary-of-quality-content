# Standard work

*Scope: Lean description of current repeatable work sequence and timing*

In Lean production, standard work is an agreed description of the current sequence and timing of a repeatable task and the work-in-process needed to perform it.

It specifies how the task is ordinarily performed so deviations and improvement opportunities can be seen.

The standard is a present way of working that can be revised when a better method is established.

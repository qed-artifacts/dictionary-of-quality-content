# Process step

*Scope: bounded activity within a mapped process*

A process step is a bounded activity in a process that moves work toward an output.

A map names the step and its place between the process’s start and end points; the useful level of detail depends on the question being asked.

Step-level yield can show where defects or rework arise, while overall yield reflects the linked process.

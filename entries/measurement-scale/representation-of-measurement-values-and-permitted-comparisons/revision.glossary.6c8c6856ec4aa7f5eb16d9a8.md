# Measurement scale

*Scope: representation of measurement values and permitted comparisons*

A measurement scale is a system for representing observations as categories or values under stated rules.

The scale determines which comparisons are meaningful: a category can distinguish kinds, an ordered scale can also rank them, and a numerical scale may permit further operations.

The number shown by an instrument is a result on a scale, not the scale itself.

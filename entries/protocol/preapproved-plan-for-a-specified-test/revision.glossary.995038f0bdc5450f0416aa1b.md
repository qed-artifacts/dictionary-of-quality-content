# Protocol

*Scope: preapproved plan for a specified test*

In planned testing, a protocol is an approved document that specifies what will be tested, how it will be done, what evidence will be recorded, and how results will be judged.

Its objectives, prerequisites, steps, and acceptance criteria should be set before testing begins.

Following the protocol documents the procedure; it does not by itself show that the tested item passed.

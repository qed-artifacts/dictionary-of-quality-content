# Probability

*Scope: numerical likelihood assigned to a defined event*

Probability is a number from 0 to 1 assigned to a defined event under a probability model, representing how likely the event is within that model.

To interpret it, identify the event, conditions, and assumptions behind the number.

It describes an event under the model; an observed outcome is separate evidence about whether that model fits.

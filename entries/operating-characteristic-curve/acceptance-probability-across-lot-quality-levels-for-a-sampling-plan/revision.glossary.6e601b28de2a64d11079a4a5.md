# Operating characteristic curve

*Scope: acceptance probability across lot quality levels for a sampling plan*

In acceptance sampling, an operating characteristic curve shows the probability that a specified sampling plan will accept a lot at each assumed level of lot quality.

For an attribute plan, the horizontal axis commonly gives the fraction or percentage nonconforming and the vertical axis gives probability of acceptance.

The curve shows how the plan balances the risks of rejecting satisfactory lots and accepting poor ones; it is a property of the plan, not a quality score for a particular lot.

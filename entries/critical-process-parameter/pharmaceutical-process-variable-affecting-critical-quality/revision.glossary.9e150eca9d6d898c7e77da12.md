# Critical process parameter

*Scope: pharmaceutical process variable affecting critical quality*

In pharmaceutical manufacturing, a critical process parameter is a process variable that needs control because changes in it can alter a product attribute essential to its quality.

Product and process understanding is used to identify such variables and set appropriate monitoring or control.

A parameter is critical because of its effect on product quality, not merely because its value happens to fluctuate.

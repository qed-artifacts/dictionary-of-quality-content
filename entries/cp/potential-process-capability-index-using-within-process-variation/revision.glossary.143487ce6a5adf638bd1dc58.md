# Cp

*Scope: potential process capability index using within-process variation*

Cp is a process capability index comparing the width between two specification limits with the process's within-process spread.

It indicates potential fit to those limits if the process is centered; it does not use the process mean.

Interpretation requires a stable process, a suitable variation estimate, and attention to the distribution and specification limits.

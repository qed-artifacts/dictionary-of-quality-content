# Failure rate function

*Scope: instantaneous conditional failure rate over item age*

For a time-to-failure model, a failure rate function assigns each time an instantaneous rate of failure among items that have survived to that time.

It describes how the conditional failure rate changes with age or exposure and is often called the hazard function.

Its value at a time is a rate per unit time, not the probability that an item has failed by that time.

# Unit of analysis

*Scope: entity level about which a study draws conclusions*

In a study, the unit of analysis is the kind of entity about which the analysis draws a conclusion, such as a person or project team.

Choosing the unit determines the level at which cases are compared and findings are stated.

A study of the same setting can ask different questions of individuals and teams, so the unit should be explicit when interpreting a result.

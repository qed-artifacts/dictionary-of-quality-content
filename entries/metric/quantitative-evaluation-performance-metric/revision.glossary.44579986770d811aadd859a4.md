# Metric

*Scope: quantitative evaluation performance metric*

In quantitative evaluation, a metric specifies what numerical value to obtain and how to obtain it for an aspect of performance.

The value produced on a particular dataset is its result.

A separate objective or decision rule says how to interpret that result.

An indicator in evaluation may be paired with a specified measure or metric.

In some quality-management uses, metric has a narrower financial or economic scope; the intended field should therefore be stated.

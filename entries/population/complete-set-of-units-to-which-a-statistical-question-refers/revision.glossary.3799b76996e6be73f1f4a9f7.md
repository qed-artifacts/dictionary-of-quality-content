# Population

*Scope: complete set of units to which a statistical question refers*

In statistics, a population is the complete set of units specified by the question being studied.

The units may be people, products, events, or measurements, and the boundaries of the set must be stated.

A sample is a subset used to learn about that population; changing the scope of the question can change which set counts as the population.

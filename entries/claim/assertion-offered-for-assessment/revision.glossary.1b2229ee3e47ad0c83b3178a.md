# Claim

*Scope: assertion offered for assessment*

A claim is a statement put forward for acceptance that can be supported, qualified, or challenged.

Claims can concern facts, values, or proposed actions. State the specific assertion and its scope so the evidence needed to assess it can be identified.

A claim is distinct from the evidence offered for it. Finding similar words in a source does not show that the source supports the same assertion.

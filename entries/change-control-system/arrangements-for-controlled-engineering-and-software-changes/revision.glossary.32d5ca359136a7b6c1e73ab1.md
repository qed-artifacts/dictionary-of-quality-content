# Change control system

*Scope: arrangements for controlled engineering and software changes*

A change control system is the set of roles, procedures, and records used to identify, evaluate, authorize, and document changes to controlled items or processes.

It assigns responsibility for reviewing change requests and retains decisions and records of the resulting state.

A change control process is the sequence followed for a particular change; the system supports consistent control across changes.

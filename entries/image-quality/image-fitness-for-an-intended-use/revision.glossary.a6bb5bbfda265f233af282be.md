# Image quality

*Scope: image fitness for an intended use*

Image quality is how well an image's properties support its intended use or interpretation.

Relevant properties can include detail, fidelity, and the ability to distinguish what matters for the task. An image suitable for one purpose may be inadequate for another.

In remote sensing, spatial resolution, geometric alignment, and radiometric information can affect which ground features can be identified or compared.

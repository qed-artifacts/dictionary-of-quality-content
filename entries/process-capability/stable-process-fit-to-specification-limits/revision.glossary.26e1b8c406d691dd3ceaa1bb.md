# Process capability

*Scope: stable-process fit to specification limits*

Process capability concerns how well a stable process can produce outputs within specified limits, given its typical variation and location.

Capability analysis compares the process distribution with the applicable specification limits. It should first establish that the process is sufficiently stable for the comparison to be meaningful.

Indices such as Cp and Cpk summarize different aspects of that comparison under stated assumptions. A favorable index is an estimate, not a guarantee that every future output will conform.

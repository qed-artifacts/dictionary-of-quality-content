# Process capability analysis

*Scope: statistical appraisal of process output relative to specifications*

Process capability analysis examines the distribution of a process's output against specified limits to estimate how consistently the process can produce acceptable results.

It uses information about process location and variation under stated conditions, commonly after checking whether the process is stable.

A capability index can summarize that comparison, but its value has meaning only with the chosen limits, data, and assumptions.

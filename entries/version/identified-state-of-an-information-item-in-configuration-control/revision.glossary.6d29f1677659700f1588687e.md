# Version

*Scope: identified state of an information item in configuration control*

In configuration control, a version is an identifiable state of an item preserved or distinguished from its other states.

A new version records a changed state so people can tell which content they are using and trace its history.

Branches may contain different versions developed from the same earlier state; a version identifier alone does not say that a change was approved for release.

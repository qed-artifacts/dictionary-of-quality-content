# Process capability index

*Scope: statistical index comparing process behavior with specification limits*

A process capability index is a numerical summary of how a process's output distribution relates to specified limits for one characteristic.

For example, Cp compares specification width with process spread, while Cpk also reflects how the process is centered within those limits.

Interpretation depends on a stable process, a suitable distributional model, and the particular index used.

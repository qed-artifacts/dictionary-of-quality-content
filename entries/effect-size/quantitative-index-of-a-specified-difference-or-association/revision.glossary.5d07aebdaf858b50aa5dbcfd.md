# Effect size

*Scope: quantitative index of a specified difference or association*

An effect size is a quantitative index of the magnitude of a specified difference or association.

Examples include a standardized mean difference, a correlation coefficient, and an odds ratio; each uses a different scale and interpretation.

The chosen index must be named; a statistically significant result does not by itself show whether the effect is important in practice.

# Software configuration management

*Scope: identification and control of changing software-system items*

Software configuration management is the organized identification, recording, and control of software items, versions, and configurations as a system changes.

It lets a team trace approved changes and reconstruct which components made up a particular system state.

Version control is one part of this work; configuration management also coordinates item selection, builds, and change requests.

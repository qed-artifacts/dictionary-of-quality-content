# Poka-yoke

*Scope: production design or device preventing a predictable mistake from producing a defect*

In production, poka-yoke is a design feature or device that prevents an inadvertent mistake from producing a defect.

It changes the task or equipment so a particular error is blocked or made harder to carry forward.

It addresses a specified error path; it does not guarantee that every kind of defect is prevented.

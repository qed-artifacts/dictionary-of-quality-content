# Data provenance

*Scope: origin and processing history of data*

In data management, data provenance is information tracing a dataset or value to its sources and the processes that produced it.

A provenance record can identify contributing inputs and transformations so a user can examine where a result came from.

It can aid quality assessment and reproducibility, but knowing the history of data does not by itself establish that the data are accurate.

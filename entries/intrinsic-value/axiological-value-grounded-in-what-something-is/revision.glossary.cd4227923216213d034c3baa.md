# Intrinsic value

*Scope: axiological value grounded in what something is*

In axiology, intrinsic value is value something has in virtue of what it is itself, rather than value derived from something outside it.

The claim concerns the ground of value; valuing something as an end rather than a means is related but conceptually distinct.

Whether pleasure, nature, or another subject actually has intrinsic value requires a separate argument.
